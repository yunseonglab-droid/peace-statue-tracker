# 소녀상 트래커

전국 평화의 소녀상 79곳의 현장 안내, 답사 동선, 방문 날짜와 메모를 관리하는 웹입니다.

## 운영

- GitHub Pages용 정적 사이트이며 `main`에 변경을 올리면 Actions에서 검사·빌드·배포합니다.
- 실행 환경: Node.js 22, `npm ci`, `npm run typecheck`, `npm run build:pages`.
- 기존 Sites 로컬 개발은 `npm run dev`로 유지됩니다. Pages는 같은 화면과 데이터를 사용합니다.
- 배포 상태는 저장소의 Actions → Deploy website에서 확인합니다. 실패한 배포는 이전 정상 사이트를 대체하지 않습니다.

## 자료와 기능의 범위

- 2026-09-10 사용자 제공 현장 답사 가이드에서 추출한 79곳입니다. 전국 전체 설치 목록이 아닙니다.
- 자료 파일은 `app/places.json`입니다. 원문 PDF, 사용자 방문 기록, 인증 키는 포함하지 않습니다.
- 대부분 지도는 장소명 검색입니다. 설치 좌표와 현장 상황을 모두 독립적으로 확인한 것은 아닙니다.
- 거리뷰·구간별 이동거리와 시간은 외부 지도 서비스에서 확인합니다. 자동 최단 경로 기능은 없습니다.
- 방문 날짜·메모·동선은 현재 브라우저의 localStorage에 보관됩니다. 기기·도메인 사이에서 동기화되지 않습니다.
- 로컬 미리보기에서 저장한 기록은 운영 사이트로 자동 이동하지 않습니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있으므로 기록 내보내기로 보관하세요.
- 로그인, 중앙 서버 데이터베이스, 관리자 편집 기능은 없습니다.

## 변경 관리

장소 ID는 기존 방문 기록과 연결되므로 변경하거나 재사용하지 마세요. 위치를 고칠 때는 원문 페이지와 확인 근거를 함께 관리해 주세요.
